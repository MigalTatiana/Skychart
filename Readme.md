Skychart - инструмент для общения и изучения звездного неба. В нём можно будет создавать задания - скайчарты - с отмеченными на фото или картах звездного неба объектами глубокого космоса, звездами и характерными точками разных систем координат для лучшего запоминания, а также делиться ими с друзьями, чтобы они могли пройти составленное вами задание.
